Web Designing Workshop-1 — HTML Assignments

This folder contains 18 standalone HTML files, one for each assignment in the supplied question document.
Open any file in a web browser to view it. You can edit the files in VS Code.

Notes:
- Assignment 8 and Assignment 10 use online placeholder/sample media, so those elements need an internet connection.
- Assignment 17 submits to submit.php as specified in the assignment; a PHP backend is not included.
- Assignment 18 demonstrates a client-side validated form; no backend is included.
